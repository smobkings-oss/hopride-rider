# HopRide rider app

Working rider beta for A2B Rides / HopRide.

## What riders can do
- Hop in with a name and mobile (stored only on this phone)
- Book an instant ride
- Schedule a pickup at least 20 minutes ahead
- Pick NW Ohio places or type a custom pin
- Compare Hop, Tesla Navigator, and Hop XL fares
- Apply promo `HOPLOCAL` for $2 off
- Watch a simulated match, arrival, and trip
- Cancel before pickup, rate after, and keep trip history

## Pricing used in the estimate
Base $3.50 + $1.85/mi + $0.28/min + $1.50 booking, times vehicle and surge. $8 minimum. Scheduled rides add $1. No real card is charged.

## Open locally
Open `index.html` in a browser. On desktop it sits in a phone frame.

## Not wired yet
